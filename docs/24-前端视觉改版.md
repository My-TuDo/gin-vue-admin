# 24-前端视觉改版：效率优先的生产工作台（2026-10-27）

> 本轮只改前端（外加一处对账响应字段的 JSON tag）。目标是让 `/jxc` 从「能用的页面集合」
> 变成一套统一、克制、可长时间使用的 B 端工作台，而不是装饰性的 C 端网页。
> 设计依据仍是 [`17-前端重设计`](17-前端重设计.md)；本文记录**落地实现**与取舍。
>
> 2026-10-27 后续：后端 Search/Dashboard/reconcile-last/checkout 已就绪，前端已按
> [`30-前端接入实现`](30-前端接入实现.md) 切到服务端筛选与聚合；本文第八节 1–3 条限制已解决。

## 一、目标与边界

用户原话：

> 实现进销存系统的前端页面风格，核心理念是：效率优先、专业克制、美观但不花哨。
> 这是一个 B 端生产工具，不是 C 端客户使用的网页。

据此确定：

- **效率优先**：一屏尽量多行、常用动作在一级入口、开单/补货尽量少的弹窗与跳转、键盘可完成主流程。
- **专业克制**：一个主色、一套中性色；不堆渐变/大圆角/大阴影；层级靠字号、字重、间距。
- **不花哨**：没有装饰性图表、没有营销式 Hero、没有无意义动效；只保留 hover / 面板进出场等必要反馈。
- **生产工具**：状态永远「颜色 + 文字」；金额/数量右对齐、等宽数字；空态说清下一步；错误给可执行的原因。

不改：

- GVA 的登录、布局、权限、路由守卫不动；`/jxc` 仍是常量路由 + 独立壳。
- 后端账务规则、单据状态机、接口路径不变。
- 不引入新的 UI 依赖。

## 二、视觉系统

### 2.1 壳层

- 左侧 `212px` 固定「墨蓝导轨」`#0d1524`，内容区跟随 GVA 主题（亮/暗）。
- 导航按任务分组：**经营**（工作台/开单/补货）、**单据与库存**、**分析与资料**；
  不再用 `◱ ◈ ▤` 这类字符占位，统一用 lucide 线框图标。
- 顶栏只放全局信息：面包屑、`Ctrl/⌘ K` 搜索入口、常驻对账状态、日期。
- 页面标题、说明与主操作在内容区顶部（`PageHeader`），顶栏不重复大标题。

### 2.2 密度与排版

| 项 | 值 |
|---|---|
| 正文 | 13px |
| 次级说明 | 12px / 11px |
| 表格行高 | 44px（表头 38px） |
| 页面标题 | 22px / 600 |
| 卡片标题 | 13px / 600 |
| KPI 数字 | 26px / 600，`tabular-nums` |
| 卡片圆角 | 8px，1px 边框，默认无阴影 |

- 金额统一走 `MoneyText`：千分位、两位小数、右对齐、负数红色；空值显示 `—`。
- 单据号、条码统一 `font-mono`；数量/金额统一 `tabular-nums`。
- 页面只保留一层卡片；卡片内不再套卡片，用分隔线分组。

### 2.3 颜色

- 主色沿用 GVA 主题色（默认蓝），只用于主操作、选中态、链接。
- 语义色：成功绿 / 警告琥珀 / 危险红 / 信息蓝；**全部配合文字**，不单独用颜色表达状态。
- 中性色由 `.jxc-app` 内的 Element Plus 变量收敛（亮/暗两套），内容区使用
  `bg-main / bg-container / text-base-text / text-muted-foreground / border-border` 语义类。
- 深色导轨是固定设计，不参与换肤；内容区随主题切换。

## 三、页面落地

### 3.1 工作台

- 四个 KPI：库存金额、今日销售额（净）、今日毛利（含毛利率）、待处理。
- **待办**按下一步动作分组：待审核采购 / 待入库采购 / 待出库销售，点击直达单据页对应筛选。
- **最近库存流水**：账本视角，方向用「入/出」文字 + 颜色，成本金额恒正。
- **可售偏低**：可售 ≤ 10，按可售升序，最多 5 条；列表可滚动，不再把内容裁掉。
- 右侧待办/预警、左侧流水，一屏内形成「看数 → 处理 → 追溯」闭环。

### 3.2 开单

- 左侧从「大卡片」改为**商品行 + 规格 chips**：一屏能看到更多商品；点规格直接加入右侧，不弹窗。
- 缺货规格保留可见但置灰，可切换「仅看有货」；默认只看有货，避免上百个零库存 SKU 淹没可售商品。
- 右侧新增**客户**选择（散客可空），明细承载数量、单价、小计、合计、实收/找零。
- 键盘：`/` 聚焦搜索、回车加入第一项、`Ctrl/⌘ + Enter` 出库、`Esc` 在非输入态清空。
- 搜索匹配顺序：条码完全匹配 → 颜色/尺码/条码包含 → 第一个有货规格；修复了「搜白/L 却加黑/M」的问题。
- 出库成功显示单号、销售额、成本、毛利；出库失败自动取消草稿并释放预留（保留原有保护）。

### 3.3 补货

- 单行搜索选择器直接追加明细；选中带出参考进价，仍可改本次进价。
- 右侧汇总：供应商、仓库、备注、行数/件数/合计、`Ctrl/⌘ + Enter` 快捷提交。
- 「提交之后」明确写出 **审核不动库存、入库才写账本**，避免把审核当入库。
- 创建成功后给出「去审核」直达该单；页头「查看采购单」进入全部采购单，不再默认只看待审核。

### 3.4 单据

- 四类页签：销售 / 采购 / 退货 / 红冲记录；每个页签带数量。
- 关键词 + 状态筛选；状态计数随关键词变化。
- 表格点行打开详情抽屉：状态、仓库、往来单位、过账时间、金额/成本/毛利、明细行（商品名 + 规格 + 条码）。
- 抽屉底部按状态给「下一步」：出库/取消、审核/入库、退货/红冲；红冲原因必填。
- 已红冲行只显示「已红冲」状态与「已冲销」操作，不再把两个标签挤在一格里。

### 3.5 库存

- 顶部摘要：有结存 SKU、结存件数、库存金额、预留/可售。
- 台账：商品名 + 条码单行、规格、仓库、结存/预留/可售、均价、结存金额；点行看完整流水。
- 流水抽屉：顶部五个余额数字；流水列「时间/单据/类型/方向/数量/成本单价/成本金额/结存/操作人」，
  结存由后端按过账顺序计算，翻页正确。
- 一键对账：通过时给「账实相符 + 检查时间」；不通过时列出类型、仓库、SKU、账本值、余额值、说明。
- 盘点：进行中的盘点排最前；进度条 + 差异项；抽屉里未录入行显示账面数作为参考，
  但 `actualQty` 仍保持 null，编辑后才计入进度；盘盈行可填成本，成本为 0 时二次确认。

### 3.6 报表

- 四个月度 KPI：销售额（净）、销售成本（净）、毛利、期末库存。
- 「经营构成」用一条成本/毛利占比条 + 采购金额/销售单/退货单；
- 「口径」直接写在页面上：销售额、成本、毛利、红冲归属月。
- 会计期间表：月份、状态、结账时间/人、期末快照；月结按钮在已结账月份自动禁用。

### 3.7 基础资料

- 商品从「一表一弹窗」改成**左列表 + 右详情**：左侧搜索/状态，右侧规格与价格、启停状态。
- 商品编辑抽屉：编码/名称/状态 + 规格矩阵（颜色、尺码、条码、售价、参考进价、启用），
  已有规格不可删除、只能停用；提交前校验条码唯一、颜色+尺码唯一。
- 往来单位：供应商/客户切换不再每次请求，两个列表一次取回，页签总数准确。
- 仓库：搜索、状态、编辑/停用；所有停用操作都带确认。

## 四、组件与共享层

新增/重写：

| 文件 | 职责 |
|---|---|
| `web/src/view/jxc/theme.css` | JXC 作用域内的 EP 尺寸/圆角/表格/抽屉/原生 button 兜底；不写业务 class |
| `web/src/components/jxc/PageHeader.vue` | 页面标题、说明、主操作 |
| `SectionCard.vue` | 单层卡片 + 可选头部 |
| `MetricTile.vue` | KPI 磁贴 |
| `EmptyState.vue` | 图标 + 标题 + 说明 + 可选操作 |
| `CommandPalette.vue` | `Ctrl/⌘ K` 页面/操作跳转，支持方向键与回车 |
| `MoneyText.vue` | 金额格式化与语义色 |
| `StatusTag.vue` | 状态字典 → 颜色 + 文字（purchase/sale/return/check/period/reversal/active） |
| `web/src/view/jxc/shared/format.js` | 时间/数量/百分比/来源类型等展示格式化 |
| `status.js` | 状态字典（纯数据，不带 class 名） |
| `keyboard.js` | 判断是否正在输入 |

实现约束：

- 业务页**不再新增 `<style scoped>`**；只有 `CommandPalette` 的面板进出场动画保留一个 scoped 块。
- 原子类全部写在 `.vue` 模板里。状态色 class 原先放在 `status.js`，会因 UnoCSS 默认不扫业务 `.js`
  而静默丢色，已移回 `StatusTag.vue`。
- 原生 `<button>` 在项目里没有 preflight 兜底，浏览器会铺 `buttonface` 灰底和 2px outset；
  在 `theme.css` 用 `:where(.jxc-app) button, :where(.jxc-overlay) button` 清零，
  特异性压到 0,0,1，EP 与 UnoCSS 的背景类都能覆盖。命令面板 teleport 到 body，所以单独加了
  `.jxc-overlay` 选择器。

## 五、键盘与效率

- `Ctrl/⌘ K`：全局命令面板（页面 + 开单/补货/对账/盘点快捷入口），`↑/↓` 选择，`Enter` 打开。
- `Alt + 1..7`：按导航顺序切换页面。
- 开单页：`/` 搜索、`Enter` 加第一项、`Ctrl/⌘ + Enter` 出库、`Esc` 清空。
- 补货页：`Ctrl/⌘ + Enter` 提交。
- 所有图标按钮补 `aria-label`；纯颜色状态一律带文字。

## 六、契约与行为变化

- **对账响应**：`ledger.Violation` 增加 `json` tag（`kind/warehouseId/skuId/expected/actual/detail`）。
  之前没有 tag，API 实际返回大写字段，前端表格取小写会是空列。前端同时兼容大小写，
  老服务端/新前端也能显示。
- **没有新增/修改业务接口**；主数据、单据、账本、报表的路径与入参不变。
- **开单页新增客户选择**：仅当用户选了客户才传 `customerId`，散客仍传 null。
- **开单页默认隐藏缺货**：可通过「仅看有货」关闭；缺货商品仍能显示，只是默认不干扰可售列表。
- **文档筛选分页在前端**：`pageSale/pagePurchase/...` 只提供分页，没有状态/关键词参数；
  视觉轮当时一次取 100 条后在浏览器内筛选、分页；2026-10-27 已切服务端筛选/分页（见 30）。
- **实收是界面字段**：后端不落收款方式/金额，实收/找零只用于收银台即时核对。
- **采购退货已接入（2026-10-27）**：单据页新增「采购退货」页签、采购单/详情退货入口、
  returnable 弹窗、草稿出库/取消；账本来源 `purchase_return` 与工作台待办同步。
  接口与联调见 [`25-采购退货单`](25-采购退货单.md)，后续服务端能力见
  [`26-后端配合需求`](26-后端配合需求.md)。

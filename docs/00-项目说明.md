# 项目名称：基于GVA开发的服装类进销存

## 1.1 项目背景
- 为什么开发？
    > 此项目是为了解决生活中的一些难点而决定开发的。
- 为什么做服装类？
    > 因为父母是做服装行业的个体户，他们没有规范的进销存逻辑，全凭人工进行进货、入库、库存盘点、销售，我开发此类的初衷即为设计一个用途简单，但是方便像我父母那样的个体户的进销存系统。

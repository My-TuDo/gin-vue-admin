## 商品管理
> 需要管理：品牌、分类、颜色、尺码、SKU
```
商品 → 颜色 → 尺码 → SKU
```
### 字段：
- 商品编码
- 商品名称
- 品牌
- 分类
- 吊牌价（销售价格）
- 备注

### 页面
- 新增
- 编辑
- 删除
- 导入
- 导出

### 业务规则
- 删除前检查SKU
- 删除前检查库存
- 删除前检查采购记录

### 异常
- 商品存在库存
- 禁止删除
---

## 采购模块
> 创建订单 → 采购入库 → 库存增加
### 功能
- 创建采购单
- 采购审核
- 采购入库
    > 点击入库 → 校验状态 → 增加库存 → 生成库存流水 → 修改采购状态 → 记录日志
- 取消采购
- 删除采购
---

## 销售模块
> 创建销售单 → 销售出库 → 库存减少
### 功能
- 售出
    > 创建销售单 → 校验商品仓库状态 → 减少库存 → 生成库存流水 → 修改销售单状态 → 记录日志
- 退货退款
    > 创建销售单(负向) → 关联原单 → 校验商品仓库状态 → 增加库存 → 修改销售单状态 → 记录日志
- 换货
    > 创建销售单(一正一负) → 换入商品关联原单 → 校验商品仓库状态 → 对应商品增减库存 → 修改订单状态 → 记录日志

## 库存
> 支持：库存查询、库存流水、库存盘点
### 功能
- 库存查询
- 库存流水
- 库存盘点
- 直接入库
    > 点击入库 → 校验状态 → 生成库存流水(入库) → 记录日志
- 直接出库
    > 点击出库 → 选择出库商品 → 校验状态 → 生成库存流水(出库) → 记录日志

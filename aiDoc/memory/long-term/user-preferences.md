# 用户长期偏好

## 语言与表达

- 默认使用中文沟通和书写项目级 AI 文档

## 文档组织偏好

- 不希望在多个工具目录中重复维护同一份 project rule
- 更倾向于 `AGENT.MD + aiDoc/` 的单一真源结构
- 更偏好 harness engineering 风格的分层文档设计
- 更偏好“讲解型示例”，而不是纯模板式示例

## 前端设计偏好

- 进销存等 B 端系统按「生产工具」设计：效率优先、专业克制、美观但不花哨
- 不要 C 端营销式页面：不要大 Hero、装饰性图表、夸张动效和大留白
- 信息密度优先：表格行高紧凑、数字右对齐且等宽、一屏尽量多行
- 状态必须「颜色 + 文字」；金额/数量不能只靠颜色区分
- 高频流程键盘优先（搜索、加入明细、提交），少用逐层弹窗
- 视觉上只保留一个主色，中性色为主；层级靠字号、字重、间距而不是边框和阴影堆叠

## 记忆管理偏好

- 不仅要保留长期记忆，也要记录每次用户提出的业务需求
- 业务记忆应独立存放，不能混入长期偏好

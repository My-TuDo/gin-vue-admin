## 已确认约束

- 采购退货金额按**原采购单价**，前端只展示/提交数量，不提交单价与金额；
- 建单为草稿，`post` 才扣库存；已过账/已取消只读；
- 可退数量以 `returnable` 为准，前端输入上限 + 后端二次校验；
- 复用 `MoneyText` / `StatusTag` / `EmptyState`，不新增金额格式化；
- 权限由后端 Casbin 逐条校验，前端不按角色隐藏入口；
- 账本来源 `purchase_return`，流水显示「采购退货」。
